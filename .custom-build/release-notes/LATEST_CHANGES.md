### 2026-11-02 托盘显示策略组选中目标、Android 应用权限页

- 托盘策略组左侧为组名，右侧以灰色显示当前选中项和延迟，紧贴箭头；展开后节点行右侧灰色显示延迟，策略组子项显示其选中节点与延迟，选中的仍是策略组时以 `组名 (最终节点)` 显示。名称与右侧说明分为两列，中间留固定间隔，不再上下交错。macOS 与 Windows 效果一致。

### 2026-10-31 Tailscale 共存

- 网络设置新增「Tailscale 共存」（桌面端，默认关闭）：Tailnet 网段不进虚拟网卡，`*.ts.net` 返回真实 IP 并交给 `100.100.100.100` 解析，系统代理自动绕过 Tailnet；各项可自定义，支持一键恢复默认。
- 订阅里写的 `tun.route-exclude-address` 不再被客户端设置覆盖，改为合并生效（包括热更新）。
- 内核访问被排除的网段时不再强制绑定 en0，按系统路由走 Tailscale。
