### 修复

- 修复应用首次安装或更新辅助工具后，内核可能在 TUN listener 启动前提前加载 TUN，导致总开关已启动但必须手动重拨虚拟网卡才能恢复网络的问题。
- 修复应用初始化时首次网络事件触发重复 TUN/DNS 重建，可能与正常启动流程发生竞争的问题。
- 修复网络恢复失败后仍提前记录新网络指纹，导致后续相同网络事件无法再次触发恢复的问题。
- 修复旧版本 DNS 备份可能混入 Bettbox 托管的 `223.5.5.5`，导致关闭或退出后仍残留自定义 DNS 的问题。

### 修改

- 首次授权需要重启内核时，先加载 `TUN=false` 的完整配置，再启动 listener，最后启用 TUN。
- 启动完成后以当前默认网络建立恢复基线，仅对真实换网事件或系统唤醒执行完整恢复。
- 本地 IP 刷新保持独立，不再使用固定超时猜测网络恢复是否完成。
