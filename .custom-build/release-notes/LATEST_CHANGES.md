### 修复

- macOS 网络指纹改为覆盖全部活动网络接口；默认出口保持不变时，第二块有线、USB 或其他接口的断开、重连、地址及 DHCP 变化也会触发 TUN/DNS 协调。
- 区分物理连接变化与 TUN 自身产生的 VPN 事件，覆盖短暂重连后仍取得相同地址的情况，同时避免恢复过程形成自触发循环。
- 新网络事件、手动停止和退出会取消过期的恢复任务；手动停止到达后，恢复流程不再重新启动监听和 TUN。
- 为 macOS 的 `route`、`networksetup`、`ipconfig` 调用增加超时和子进程回收，避免系统命令长期占用恢复与启停链路。
- 退出时先隐藏窗口，并为后台清理及系统 DNS 恢复设置时间边界，避免网络异常后普通退出长期无响应。
