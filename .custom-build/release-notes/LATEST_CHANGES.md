### 修复

- 移除 macOS 网络状态未变化、恢复请求被合并时产生的高频空操作日志，并修正重复的 `[APP]` 日志前缀；实际换网与唤醒恢复逻辑保持不变。
- 恢复 macOS 托盘菜单按点击读取最新状态并重建，修复测速期间或菜单更新后首次切换节点、“显示”等操作无效的问题。
- 菜单展开期间只原位更新当前菜单，二级菜单父项仅负责展开，不再响应无效点击。
- 节点延迟结果恢复独立右对齐列；测速时保留闪电图标并显示“测速中...”。

### 优化

- Release 同时列出相较上一自定义版本的上游提交与自定义改动，不再只重复固定功能描述。
- 自定义应用代码变化但未更新增量说明时停止发布，避免再次生成缺少实际变更内容的 Release。
- 同步时记录四个功能分支的准确提交，打包前再次校验分支提交与包含关系；缺少任一功能时直接停止构建。
