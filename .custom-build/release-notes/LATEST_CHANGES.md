### 新增

- macOS 菜单栏支持显示实时上传、下载速率，默认关闭。
- macOS 托盘左右键可分别设置为“显示面板”或“显示菜单”，默认左键显示面板、右键显示菜单。
- 关闭“显示隐藏项”时，按住 Option 点击托盘可临时显示隐藏策略组。

### 调整

- 移除旧“托盘增强”总开关，托盘策略组菜单直接可用；速率与点击行为保留为“更多 → 增强工具”中的独立一级设置。
- 自定义构建改为严格以源仓库最新 `main` 为基线，再叠加尚未合并的功能分支与补丁。

### 修复

- 修复从托盘重启内核后，图标持续置灰且菜单仍显示“启动”，必须打开主窗口才恢复的问题。
- 修复托盘策略组测速按钮状态与运行时状态不同步，以及菜单重建后点击映射失效的问题。
