### 修复

- 修正 macOS 首次安装或更新特权工具后的 TUN 启动顺序：内核重启后先加载关闭 TUN 的基础配置，确认监听器启动成功后才恢复 TUN，避免启动状态正常但流量无法进入内核。
- 核心配置、监听启停、连接关闭及 DNS/Fake-IP 缓存刷新不再把超时或 `false` 返回值当作成功，避免恢复流程在前一步失败后仍继续写入错误运行状态。
- 监听器停止失败时先重新确认监听器可用；监听器启动失败时不再恢复 TUN，避免形成所有捕获流量均无法处理的网络黑洞。
- 手动停止、退出或应用销毁会同时取消后续监听器和 TUN 恢复，不再只取消中间的网络清理步骤。

### 可靠性

- 换网或系统唤醒后的自动恢复发生瞬时异常时，等待两秒后最多重试一次；第二次仍失败则停止，不会形成无限重试和高频日志。
- 增加授权重启后无 TUN 初始化、监听器失败不恢复 TUN、外部取消及单次重试等回归测试。
