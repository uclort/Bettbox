### 2026-11-03 内置 Tailscale 节点

- 网络设置新增「Tailscale」分组。新开关「内置 Tailscale 节点」（默认关闭）：Bettbox 内核作为一台独立设备加入 Tailnet，`*.ts.net` 与 `100.64.0.0/10` 自动转给它，不需要安装或运行 Tailscale App。需要开启虚拟网卡或系统代理；只负责本机访问 Tailnet，不能让其他设备访问本机。
- 齿轮内可查看节点状态（设备名、Tailnet IP、账号），点「登录 Tailscale」在浏览器授权，登录状态保存在本机，重载配置无需重新登录；也可填 Auth Key、设备名、出口节点，或关闭子网路由。
- 原「Tailscale 共存」改名「Tailscale App 共存」，仍需 App 保持运行。两个都开时以内置节点为准。新增「Tailscale 接入说明」，介绍两种方式的区别、同时开启的效果，以及什么时候需要 Tailscale App。Android 只显示内置节点，接入说明也换成 Android 版本：系统同一时间只允许一个 VPN，所以没有 App 共存。
- 内置节点设置页新增「设备」列表：显示 Tailnet 中所有设备的在线状态、IP、系统，以及当前是直连还是经 DERP 中继，点按复制 IP，页面打开时自动刷新。
- 修复切换开关或重载配置后，内置节点在 Tailscale 后台显示「Duplicate node key」、状态一直停在「正在连接」：新节点启动前会先关掉旧节点。
- 内置节点不会出现在 include-all 策略组里，不参与测速和自动选择。

### 2026-11-02 托盘显示策略组选中目标、Android 应用权限页

- 托盘策略组左侧为组名，右侧以灰色显示当前选中项和延迟，紧贴箭头；展开后节点行右侧灰色显示延迟，策略组子项显示其选中节点与延迟，选中的仍是策略组时以 `组名 (最终节点)` 显示。名称与右侧说明分为两列，中间留固定间隔，不再上下交错。macOS 与 Windows 效果一致。
- Fallback、URLTest 等自动选择的策略组，托盘子菜单中的节点改为灰色（与右侧延迟同色），点击无反应且不会关闭菜单；只有手动选择（Selector）组的节点可点选。
- 修复 macOS 按住 Option 打开托盘（显示隐藏策略组）时，点击延迟测试没有加载动画、延迟不刷新的问题。
- Windows 支持按住 Alt 点击托盘图标临时显示隐藏策略组（对应 macOS 的 Option）。
- Windows 托盘菜单新增字母快捷键：菜单打开时按 M 显示窗口、D 网络面板、S 系统代理、E 虚拟网卡、R 重启内核、Q 退出，与 macOS 的 ⌘ 快捷键字母一致。
- Tailscale 共存开启后，`tailscale.com` / `tailscale.io`（控制面、登录、DERP）固定返回真实 IP，DNS 服务器与分流规则不变；修复开启虚拟网卡时 Rex 等内嵌 Tailscale（tsnet）的应用点「Sign in」一直无反应。请勿把 `tailscale.com` 填进 MagicDNS 域名，MagicDNS 无法解析它，浏览器会报 NXDOMAIN。
- 关于页新增「应用权限」（Android）：列出 Bettbox 所需全部权限与授权状态，可直接申请或跳转系统设置。
- 补充 Android 17 本地网络权限（ACCESS_LOCAL_NETWORK）运行时申请，与通知权限合并为一次系统弹窗；修复未授权时无法连接同一网段设备（如局域网 HTTP 代理）、测速超时和 502。

### 2026-10-31 Tailscale 共存

- 网络设置新增「Tailscale 共存」（桌面端，默认关闭）：Tailnet 网段不进虚拟网卡，`*.ts.net` 返回真实 IP 并交给 `100.100.100.100` 解析，系统代理自动绕过 Tailnet；各项可自定义，支持一键恢复默认。
- 订阅里写的 `tun.route-exclude-address` 不再被客户端设置覆盖，改为合并生效（包括热更新）。
- 内核访问被排除的网段时不再强制绑定 en0，按系统路由走 Tailscale。
