### 2026-10-22 修复网络面板连接状态、活动时间与排序

- 连接时间不再直接显示创建时刻：列表显示“最后活跃”或观察到的“结束于”，历史缺少活跃与结束证据时显示“最后活跃未知”；详情单独显示创建时间和可确认的时长。
- “建立中 / 已连接 / 已结束 / 失败”统一为黄 / 绿 / 灰 / 红；请求页合并活动连接快照，并按连续快照的累计流量差显示实时上下行速率。
- 请求与活动连接列表新增智能、下载速度、上传速度、总流量、最后活跃和创建时间排序，并按 250 ms 刷新活动速率。
- 内核在 TCP/UDP 拨号前发布 pending 请求，成功或失败沿用同一 UUID 原位更新，最近请求可显示拨号阶段的“建立中”状态。
